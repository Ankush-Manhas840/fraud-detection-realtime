What Docker is

Think of a lunch box. Instead of telling someone "buy rice, cook it this way, add this curry", you hand them a sealed box with the meal already inside. It tastes the same in any kitchen.

Docker packs a program together with everything it needs (the right Python, libraries, settings) into one sealed box, so it runs the same on your laptop, a friend's laptop or a cloud server. No more "it works on my machine".

Words you will meet

ImageThe recipe: a frozen, read-only package of a program and everything it needs.
ContainerThe cooked dish: a running copy of an image. One image can run as many containers.
Docker HubA public shelf of ready-made images, like redis:7 or apache/kafka.
TagThe version after the colon: redis:7 means Redis version 7.
Port mapping-p 6379:6379 connects a door on your laptop to a door inside the container.
VolumeA folder that survives when a container is deleted, so data is not lost.
DockerfileYour own recipe for building an image, step by step.
Docker ComposeOne file that starts several containers together. Your project already has docker-compose.yml.
Daemon (engine)The part that runs containers. It starts when Docker Desktop is open.
docker vs docker composedocker handles one container. docker compose handles a group.

Check yourself

Answer out loud, without notes. These are common interview questions.

What problem does Docker solve?

"It works on my machine." A container carries the program with its exact environment, so it runs the same everywhere.

Image or container: what is the difference?

An image is the frozen recipe. A container is a running copy of it. You can start many containers from one image.

How is a container different from a virtual machine?

A virtual machine runs a whole separate operating system and is heavy. Containers share the host's kernel, so they start in seconds and use far less memory.

What does -p 8000:8000 mean?

Connect port 8000 on your laptop to port 8000 inside the container, so your browser can reach the program inside.

Why is data lost when a container is deleted, and how do you keep it?

A container's own storage is thrown away with it. A volume stores data outside the container, so it survives.

What does each Dockerfile line do: FROM, COPY, RUN, CMD?

FROM picks the starting image (like python:3.12). COPY puts your files in. RUN executes a build step, like pip install. CMD is the command that runs when the container starts.

How did you use Docker in your project?

Docker Compose runs Kafka and Redis locally, and the FastAPI service has its own image, so the whole fraud pipeline starts with one command and runs the same on AWS.
